# The Midterm

A choose-your-own-adventure game about how exam stress affects memory and focus. NSCI 140 (UBC) Group 3 project.

Play it: https://thomas-wood-eng.github.io/nsci140-midterm-game/

- Open `index.html` in any browser to play locally; no build step or install.
- All story content and numbers are in `story.js`. Game rules are in `rules.js`.
- Run `node check.js` after editing `story.js` to check the story structure and simulate playthroughs.

Brain illustration: National Institute on Drug Abuse (NIDA), public domain, via Wikimedia Commons.
Some exam questions are adapted from the NSCI 140 Week 7 practice exam.
